# FPP TD3 target 비관성 검정 (2026-11-25, 실행 전에 고정)

## 1. 묻는 것

FPP TD3에서 SABER는 HER보다 높다(seed 11–30, AUC +0.045 [+0.018, +0.073]). 성능이 같은 초반(100k–400k)에 SABER critic의 Q 수준이 더 높다는 것이 지금 남은 유일한 경로 후보다(`../fpp_td3_cumulative_effect_n20_20261118/`, L2 +0.54, 17/3).

TD3는 target에 두 target critic 중 작은 값을 쓴다. 이 비관성을 줄여 Q 수준을 직접 올렸을 때,

1. HER만으로 SABER만큼 좋아지는가?
2. 그 위에서 SABER의 이득이 남는가?

## 2. 조작

target을 `min(Q1', Q2') + α·|Q1' − Q2'|`로 바꾼다. α = 0이면 TD3 그대로이고, α = 0.5이면 두 값의 평균이다. 다른 것은 바꾸지 않는다(target 정책 노이즈, 지연 갱신, actor가 Q1을 쓰는 것 모두 그대로).

- 코드는 `experiment_FPP/td3_{her_baseline,saber_critic_only_v4}_ls512`의 `code/src`를 `sources/`에 복사하고 옵션 `--td3_target_mix_alpha` 하나를 더한 것이다. 바뀐 줄은 `sources/PATCH_{her,saber}.diff`에 있다(두 arm에 같은 15줄).
- `launch.py verify`로 확인했다(2026-11-25, cpu, 8,000 step, 갱신 3,000회). α = 0이면 원래 코드와 actor·critic·target 가중치 30개가 비트 단위로 같고, α = 0.5이면 다르며, `config.json`에 α가 기록된다(`outputs/verify_report.json`).
- 기존 seed 11–15의 150k·400k checkpoint에서 정책 행동의 |Q1 − Q2| 평균은 약 1.0이었다. α = 0.5는 target을 한 step에 약 0.5 올리는 셈이고, bootstrap으로 누적되므로 SABER가 만든 차이(+0.5)보다 훨씬 큰 조작일 수 있다. 그래서 α = 0.25도 함께 돌린다.

## 3. 실행

| arm | α | seed | 실행 |
|---|---|---|---|
| HER, SABER | 0 | 11–30 | 기존 20쌍 그대로 (`../fpp_td3_primary_checkpoint_rerun_20261110/outputs/runs_n20`) |
| HER, SABER | 0.25 | 11–30 | 새로 40개 |
| HER, SABER | 0.5 | 11–30 | 새로 40개 |

- 명령은 기존 20쌍과 같고 학습 코드 경로, 출력 폴더, α만 다르다. 1M step, cuda, thread 1개.
- 동시 실행은 장비 전체 trainer 18개까지다. 실패한 실행은 다시 돌리지 않고, 실패가 나오면 새 실행을 시작하지 않는다.

## 4. 분석 (`analyze.py`, 실행 전에 고정)

지표와 통계는 기존 20쌍과 같다. `eval/success_mean`의 [10k, 1M] AUC를 seed로 짝지어 비교한다. paired bootstrap 100,000회(seed 20261113)와 sign-flip p를 쓴다. final-quarter AUC와 최종 성공률은 같이 보고만 한다.

α마다 다음을 계산한다. 주 판정은 α = 0.5, 보조는 α = 0.25다.

| 비교 | 뜻 |
|---|---|
| C1: HER(α) − HER(0) | target을 덜 비관적으로 하면 HER가 좋아지는가 |
| C2: SABER(α) − HER(α) | 그 위에서 SABER 이득이 남는가 |
| C3: [SABER(0) − HER(0)] − [SABER(α) − HER(α)] | 이득이 얼마나 줄었는가 (보조) |
| C4: HER(α) − SABER(0) | 바꾼 HER가 원래 SABER에 닿는가 (보조) |

**읽는 규칙 (AUC 기준)**

- C1: 구간 하한 > 0이면 "올랐다", 상한 < 0이면 "내렸다", 아니면 "그대로".
- C2: 구간 하한 > 0이면 "남는다". 상한 < +0.0225(원래 이득의 절반)이면 "절반도 남지 않는다". 아니면 "판정 불가".

| C1 | C2 | 판정 |
|---|---|---|
| 무엇이든 | 남는다 | **비관성으로 설명되지 않는다.** SABER 이득은 target을 덜 비관적으로 해도 남는다 |
| 올랐다 | 절반도 남지 않는다 | **비관성 완화 경로와 맞는다.** target만 바꿔도 HER가 오르고 SABER가 더하는 것이 거의 없다 |
| 그대로·내렸다 | 남는다가 아님 | **검정 불성립.** 조작이 HER를 올리지 못했으므로 Q 수준을 올리면 이득이 재현되는지 알 수 없다 |
| 올랐다 | 판정 불가 | 판정 불가 |

- 두 α의 판정이 다르면 둘 다 그대로 보고하고 하나로 합치지 않는다.
- **조작 확인:** 초반(100k–400k) `critic/q_policy_mean`의 HER(α) − HER(0)를 보고한다. 누적 효과 분석의 L2와 같은 지표다. 판정에는 쓰지 않고, "검정 불성립"을 해석할 때 본다.

**미리 적어 두는 한계**

- C3의 표준오차는 약 0.02로 예상한다(쌍 차이의 SD 0.063, 20쌍). 이득이 전부 사라져야(+0.045) 구간이 0을 벗어난다. 그래서 C3은 판정에 쓰지 않는다.
- "절반도 남지 않는다"는 이득이 0이라는 뜻이 아니다.
- 비관성 완화 경로와 맞는다는 판정이 나와도, SABER가 Q 수준을 올리는 이유는 이 실험으로 알 수 없다.
- 이 가설은 20쌍 결과를 본 뒤에 세운 것이다. FPP에서 TD3 HER만 AUC가 낮다는 점(DDPG 0.600, SAC 0.542, TD3 0.371)도 사후에 본 정황이다.

## 6. 추가 (2026-11-25 09:50 UTC, 이 실험의 평가 결과를 하나도 보기 전)

실행을 시작한 뒤 가치 편향 측정(`../fpp_td3_value_bias_n20_20261125/`)이 끝났다. 초반 구간에서 HER critic과 SABER critic 모두 300-step 실제 return보다 높았다(편향 +5.5, +6.4). 그래서 두 가지를 덧붙인다. 4절의 판정 규칙과 `analyze.py`는 바꾸지 않는다.

- **이름.** 이 실험이 보는 것은 "과소추정을 줄이면 좋아지는가"가 아니다. critic은 이미 실제 가치보다 높다. 보는 것은 "target을 덜 비관적으로 해서 Q 수준을 더 올리면 좋아지는가"다.
- **C1이 "내렸다"로 나올 때.** 4절은 이를 "검정 불성립"으로 둔다. 판정은 그대로 두되, 두 α 모두에서 HER가 내려가면 "Q 수준을 올리는 것은 이득의 경로가 아니다"쪽의 근거로 따로 적는다. SABER가 만든 Q 수준 차이도 같은 방향(더 높게)이기 때문이다.
