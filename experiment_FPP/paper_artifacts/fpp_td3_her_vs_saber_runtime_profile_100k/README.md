# FPP TD3 HER vs HER+SABER Runtime Profile 100k

This compact artifact contains the completed seed-1, 100k-step implementation
profile for matched TD3+HER and TD3+HER+SABER runs. It is a hardware-specific
implementation profile, not a learning-performance or wall-clock superiority
claim.

## Primary profile result

The measured profile window is (20k, 100k].

| Method | Training seconds | Steps/sec excluding eval | Training-loop ms/env step |
|---|---:|---:|---:|
| TD3+HER | 645.042759 | 124.022786 | 8.063034 |
| TD3+HER+SABER | 1930.673057 | 41.436327 | 24.133413 |

SABER's measured relative training-time overhead is
199.309%; measured throughput is
66.590% lower. Support and weighting
accounts for 15.027636 ms per environment step
and 62.269% of the SABER training loop.

These numbers must not be linearly extrapolated to 1M steps.

## Included results

Each run contains "config.json", "env_snapshot.json", "summary.json",
"runtime_profile_summary.json", "runtime_profile_components.csv", and
"runtime_profile_events.jsonl". The "comparison/" directory contains the JSON,
CSV, and Markdown comparison generated by the experiment analyzer.

Absolute repository prefixes in JSON path fields were converted to
repository-relative paths. Text line endings were normalized to LF. Numerical
and event values were not changed. Original paths and SHA256 values are
recorded in "artifact_manifest.json".

## Source

The experiment implementation is under
"experiment_FPP/td3_runtime_profile_her_vs_saber_100k/". Both methods used the
same source snapshot and seed mapping.

## Excluded files

Model checkpoints, full training "metrics.csv"/"metrics.jsonl", run logs,
checkpoint metadata, and the orchestration queue log are omitted. They are not
needed to reproduce the profile comparison from the included summaries and
event records.
