# SABER AAAI-27 LaTeX Sources

The long review draft and the page-limited submission skeleton are maintained separately.

## Files

- `saber_aaai27_draft_kr.tex`: full Korean review draft with appendix and stress evidence.
- `saber_aaai27_submission_kr.tex`: compact English submission skeleton; critical claims and controls stay in the main body.
- `saber_refs.bib`: shared bibliography.
- `aaai2027.sty`: AAAI-27 style file copied from `AuthorKit27/`.
- `aaai2027.bst`: AAAI-27 bibliography style copied from `AuthorKit27/`.
- `build_pdf.sh`: builds either source and copies the stable result to `output/pdf/`.

## Build

```bash
cd paper
./build_pdf.sh saber_aaai27_draft_kr.tex
./build_pdf.sh saber_aaai27_submission_kr.tex
```

The generated PDFs are:

- `output/pdf/saber_aaai27_draft_kr_latest.pdf`
- `output/pdf/saber_aaai27_submission_kr_latest.pdf`

Numerical tables are checked against `analysis/result_pipeline/output/`. Paired bootstrap summaries use `paired_bootstrap_ci.csv`; exact sign-flip, sign-count, and leave-one-seed-out checks use `paired_exact_inference.csv`. FPP SAC comparisons use the exact 50k common-grid artifact under `experiment_FPP/paper_artifacts/fpp_sac_controls_and_redq_1m/common_grid_50k/`; native metrics remain preserved for audit. The matched FPP HGR baseline is under `experiment_FPP/paper_artifacts/fpp_ddpg_hgr_pair_priority_is_1m/` and must be labeled `HGR (matched DDPG+HER)`, not an exact reproduction of the original paper configuration. The TD3 D8 sensitivity source is `experiment_FPP/paper_artifacts/fpp_td3_saber_action_diversity_d8/`; it is a weak-gate sensitivity result, not evidence that diversity is harmful. The paired FPP TD3 confirmatory source is `experiment_FPP/paper_artifacts/fpp_td3_her_vs_saber_n10_1m/`; it contains HER/SABER seeds 1--10 on the exact 10k grid. The original n=5 rows remain the cross-backbone comparison, while the n=10 package supplies a separate paired AUC confirmation. Its frozen interval is imported from `analysis/analysis_results.json`; exact sign-flip and leave-one-out values are independently regenerated by the repository pipeline. The support-query source is `experiment_FPP/paper_artifacts/fpp_td3_saber_query_ablation_ls512/`; it compares HER, Main SABER, replay-query, shuffled-policy-query, and count-unmatched context-count-only on the exact 10k grid. The strict assignment source is `experiment_FPP/paper_artifacts/fpp_td3_saber_context_eligible_count_matched/`; it matches context eligibility, the counterfactual Main count, and raw/normalized weight distributions per update. Main-minus-control is `+0.0516[-0.0165,0.0992]` AUC on 4/5 positive seeds, so the count confound is removed but membership's independent performance contribution is not interval-closed. The hardware-specific TD3 profiler is under `experiment_FPP/paper_artifacts/fpp_td3_her_vs_saber_runtime_profile_100k/`.

The canonical context-matched source artifact is not itself the final double-blind ZIP. Build the sanitized review copy with `python3 analysis/package_fpp_td3_context_matched_review.py`. The command preserves the canonical directory, redacts source-user namespaces and Git commit IDs, regenerates post-redaction manifests, and writes `output/review_artifacts/fpp_td3_saber_context_eligible_count_matched.zip`. Do not ship the canonical repository directory unchanged.

DrawerOpen uses three separate compact packages. `metaworld_Drawer_Open_DDPG_HGR/paper_artifacts/drawer_open_ddpg_hgr_sampler_only_2m/` is the five-seed HGR-style sampler-only ablation and is not canonical HGR. `metaworld_Drawer_Open_DDPG/paper_artifacts/drawer_open_ddpg_saber_seed_extension_2m/` separates the original SABER seeds 1--5, diagnostic extension seeds 6--10, and descriptive pooled seeds 1--10 result. Only the original cohort has matched method rows, so the pooled result must not be used for paired inference. The separate `metaworld_Drawer_Open_DDPG/DIAGNOSIS_B3_CRITIC_ONLY_10SEED_KO.md` report combines a diagnostic rerun of seeds 1--5 with diagnostic seeds 6--10; its in-sample residual and phase analyses must not be conflated with the original pooled performance cohort or presented as causal generalization evidence. Corrected DrawerOpen Shuffled-weight summaries expose `reported_runtime_total_sec` and `reported_steps_per_sec`; aggregation must prefer these full-run fields over resume-only runtime values. `metaworld_Drawer_Open_REDQ/paper_artifacts/drawer_open_redq_her_tqb_2m/` contains five complete 2M REDQ-HER TQB seeds on the exact 10k grid and must be labeled an `N=10, M=2, UTD=4` architecture/compute-scaled reference. Its raw config retains the legacy method field `b0_ddpg_her`; REDQ identity is verified from the packaged trainer, ten-critic ensemble, subset target, UTD-4, automatic entropy tuning, and target-Q bound. The paper reports sample SD `0.314`, not the legacy README's population-SD value. The DrawerClose sampling ablation is under `metaworld_Drawer_Close_DDPG_HGR/paper_artifacts/drawer_close_ddpg_her_hgr_2m/` and must likewise remain labeled `HGR-style sampler-only`.

## Important

Neither source is final-submission ready. The long review draft loads `kotex`; the English submission skeleton does not. For the final AAAI-27 submission:

1. Translate the paper body to English.
2. Remove `\usepackage{kotex}` from the translated long-draft/supplement sources.
3. Keep `\usepackage[submission]{aaai2027}`.
4. Compile with PDFLaTeX.
5. Include the anonymized reproducibility package and only figures used by the submission source.
6. Replace the paper-ID comment with the assigned OpenReview ID; the visible content areas are already set to Reinforcement Learning (primary) and Robotics (secondary).

The final AAAI technical-content limit is 7 pages, excluding references. The long review draft must not be submitted as the main paper.
